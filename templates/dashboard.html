Unsupervised Clustering Evaluation Metrics
Silhouette Score

{{ metrics.silhouette_score if metrics else '0.4852' }}

Range: -1 to +1 (Higher is better)

Measures how similar an object is to its own cluster compared to other clusters. Scores > 0.4 indicate well-separated, distinct clusters.

Davies-Bouldin Index

{{ metrics.davies_bouldin_index if metrics else '0.8859' }}

Range: 0 to ∞ (Lower is better)

Measures the average similarity between each cluster and its most similar one. Values below 1.0 signify compact clusters that are well-separated.

Calinski-Harabasz Score

{{ metrics.calinski_harabasz_score if metrics else '1065.72' }}

Variance Ratio Criterion (Higher is better)

Ratio of the sum of between-cluster dispersion to within-cluster dispersion. High values validate tightly grouped, distinct clusters.

WCSS / Inertia

{{ metrics.wcss if metrics else '2081.64' }}

Within-Cluster Sum of Squares

Measures the internal tightness of clusters. Decreases as K increases; optimal point is identified via the Elbow curve inflection.
