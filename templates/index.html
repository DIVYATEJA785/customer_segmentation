End-to-End Machine Learning Pipeline Architecture
1. Data Ingestion & Preprocessing

Loads multi-feature customer records. Handles missing values, performs deduplication, encodes categorical variables (Gender), and normalizes features using StandardScaler.

2. Cluster Optimization & Evaluation

Tests cluster parameters from K=2 to 10. Automatically evaluates using the Elbow Method (WCSS), Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Score.

3. Dynamic Profiling & Prediction

Calculates cluster centroids, dynamically labels business personas, visualizes 2D PCA clusters, and serves real-time single customer inference via the web portal.
